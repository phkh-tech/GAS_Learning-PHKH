1. The big picture1. Bức tranh tổng thể

GAS has six main parts. Every GAS feature in this project combines them:

GAS có sáu thành phần chính. Mọi tính năng GAS trong dự án này đều là sự kết hợp của chúng:

Ability System Component (ASC)

The "brain" component on the character. It owns everything else: attributes, active effects, tags and granted abilities.
Here: AbilitySystemComponent created in ACharacterBase.

Component "bộ não" trên nhân vật. Nó sở hữu mọi thứ còn lại: attribute, effect đang chạy, tag và các ability đã được cấp.
Trong dự án: AbilitySystemComponent được tạo trong ACharacterBase.

Attribute Set

The numbers: Health, Stamina and so on.
Here: UBaseAttributeSet (Health, MaxHealth, Stamina, MaxStamina, Damage).

Các con số: Health, Stamina, v.v.
Trong dự án: UBaseAttributeSet (Health, MaxHealth, Stamina, MaxStamina, Damage).

Gameplay Ability (GA)

Something the character does: dash, attack, die.
Here: GA_Dash, GA_ClawAttack, GA_Death, GA_MeleeAttack_Punch.

Một việc nhân vật làm: lướt, tấn công, chết.
Trong dự án: GA_Dash, GA_ClawAttack, GA_Death, GA_MeleeAttack_Punch.

Gameplay Effect (GE)

A data-only "rule" that changes attributes and/or adds tags, either once, for a duration or forever.
Here: GE_Dash_Cost, GE_Dash_Cooldown, GE_ClawĐamage, GE_StaminaRegen…

Một "luật" chỉ chứa dữ liệu, thay đổi attribute và/hoặc thêm tag: một lần, trong một khoảng thời gian, hoặc vĩnh viễn.
Trong dự án: GE_Dash_Cost, GE_Dash_Cooldown, GE_ClawĐamage, GE_StaminaRegen…

Gameplay Tag

Hierarchical labels like Cooldown.Dash or State.Death. Everything in GAS talks using tags.
Here: Config/DefaultGameplayTags.ini.

Nhãn phân cấp như Cooldown.Dash hoặc State.Death. Mọi thứ trong GAS "nói chuyện" với nhau bằng tag.
Trong dự án: Config/DefaultGameplayTags.ini.

Gameplay Cue (GC)

Cosmetic only: VFX, sound, camera shake. It never changes gameplay.
Here: GC_Dash (tag GameplayCue.Movement.Dash).

Chỉ để trình diễn: VFX, âm thanh, rung camera. Không bao giờ thay đổi gameplay.
Trong dự án: GC_Dash (tag GameplayCue.Movement.Dash).

4. The Attribute Set: UBaseAttributeSet4. Attribute Set: UBaseAttributeSet

An attribute is a float with two values:

Một attribute là một số float có hai giá trị:

  • BaseValue: the permanent value. Instant effects (damage, potions) change this.
  • CurrentValue: BaseValue plus any temporary buffs from Duration/Infinite effects. This is what the UI should show.
  • BaseValue: giá trị vĩnh viễn. Effect Instant (sát thương, bình máu) thay đổi giá trị này.
  • CurrentValue: BaseValue cộng với các buff tạm thời từ effect Duration/Infinite. UI nên hiển thị giá trị này.

You can see both in your Blueprint: in BP_SaberTooth-ASC, the Get MaxStamina node has the pins MaxStamina_BaseValue and MaxStamina_CurrentValue.

Bạn có thể thấy cả hai trong Blueprint của mình: trong BP_SaberTooth-ASC, node Get MaxStamina có hai pin MaxStamina_BaseValue và MaxStamina_CurrentValue.

4.4 Meta attributes: Damage4.4 Meta attribute: Damage

Damage is a meta attribute: a temporary "inbox" value, not real character state. The standard pattern works like this:

Damage là một meta attribute: một giá trị "hộp thư đến" tạm thời, không phải trạng thái thật của nhân vật. Mẫu chuẩn hoạt động như sau:

  1. A damage GE adds, say, 20 to the target's Damage instead of subtracting from Health.
  2. In PostGameplayEffectExecute you read Damage, reset it to 0 and subtract it from Health. This is the place to apply armour, resistances, crits, hit reactions and death checks.
  1. GE sát thương cộng, ví dụ, 20 vào Damage của mục tiêu thay vì trừ thẳng vào Health.
  2. Trong PostGameplayEffectExecute bạn đọc Damage, đặt nó về 0 và trừ vào Health. Đây là nơi để tính giáp, kháng, chí mạng, phản ứng khi trúng đòn và kiểm tra chết.
// The meta-attribute pattern (not in your code yet; a good exercise)
// Mẫu meta attribute (chưa có trong code của bạn; một bài tập tốt)
if (Data.EvaluatedData.Attribute == GetDamageAttribute())
{
    const float LocalDamage = GetDamage();
    SetDamage(0.f);
    if (LocalDamage > 0.f)
    {
        SetHealth(FMath::Clamp(GetHealth() - LocalDamage, 0.f, GetMaxHealth()));
        // if (GetHealth() <= 0) -> send an event / apply GE_Death · gửi event / áp GE_Death
    }
}
Right now Damage is declared but PostGameplayEffectExecute doesn't handle it. Any GE that modifies Damage therefore has no visible result. Check which attribute GE_ClawĐamage / GE_FistDamage modify. If it's Health, they work, but they skip the meta-attribute step. Hiện tại Damage đã được khai báo nhưng PostGameplayEffectExecute chưa xử lý nó. Vì vậy GE nào thay đổi Damage sẽ không có kết quả nhìn thấy được. Hãy kiểm tra GE_ClawĐamage / GE_FistDamage đang thay đổi attribute nào. Nếu là Health thì chúng vẫn hoạt động, nhưng bỏ qua bước meta attribute.
